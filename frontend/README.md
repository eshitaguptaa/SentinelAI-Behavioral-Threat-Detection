# SentinelAI Frontend

React + TypeScript client for the SentinelAI cybersecurity platform.

## Stack

- Vite
- React 19
- TypeScript
- Tailwind CSS v4
- React Router
- TanStack Query
- Axios
- Recharts
- Framer Motion
- Lucide React
- shadcn/ui

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Path alias `@/` maps to `src/`
- UI primitives are managed via shadcn/ui (`npx shadcn@latest add <component>`)
- Application screens and business logic are not implemented yet
